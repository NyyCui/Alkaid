# 瑶光台（Alkaid）

瑶光台是一个 Windows 本地应用工作台。你可以在同一个桌面里记便签、整理工作区文件、安装和运行自己或他人开发的小工具。开发者可以把前端构建产物打成 .ypkg 应用包，并通过 SDK 使用授权的文件、存储、网络和插件能力。
