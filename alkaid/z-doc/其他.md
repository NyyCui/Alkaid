# CEF 命令行参数参考

> **版本**：151.3.14+g5d67476+chromium-151.0.7922.72

CEF 基于 Chromium 内核，支持两类命令行参数：

1. **CEF 专用参数** — `CefSettings` 结构体字段 或 命令行 `--cef-xxx`
2. **Chromium 通用参数** — `--xxx` 格式，通过 `CefCommandLine::AppendSwitch` 设置

## 设置方式

- 在 `CefApp::OnBeforeCommandLineProcessing()` 回调中修改
- 或通过 `CefCommandLine::AppendSwitch` / `AppendSwitchWithValue` 方法

## 参数生效范围

CEF 采用多进程架构（浏览器主进程 + 渲染进程 + GPU 进程 + 工具进程等）。主进程的命令行参数默认会传递给子进程，但并非所有参数在子进程中都有实际效果。

| 生效范围 | 参数示例                                                                  |
|----------|---------------------------------------------------------------------------|
| 仅主进程 | 网络代理、缓存存储、UI 窗口、CEF 路径配置、进程模型控制等                 |
| 渲染进程 | `--js-flags`、渲染后台化控制等                                            |
| GPU 进程 | GPU 加速、ANGLE/GL 后端选择等                                             |
| 所有进程 | 日志级别（`--v`）、特性开关（`--disable-features` / `--enable-features`） |

## ★ 高频推荐配置

以下参数在 CEF 桌面应用开发中使用频率最高，按开发阶段分类。

### 🔧 开发调试阶段

| 参数                           |   推荐度   | 说明                                                                                                                                                 |
|--------------------------------|:----------:|------------------------------------------------------------------------------------------------------------------------------------------------------|
| `--remote-debugging-port=9222` | ⭐⭐⭐⭐⭐ | 启用 DevTools 远程调试，可通过 `chrome://inspect` 连接调试前端页面。这是 CEF 开发中最核心的调试手段。等效 `CefSettings.remote_debugging_port = 9222` |
| `--enable-logging` `--v=1`     | ⭐⭐⭐⭐⭐ | 启用 Chromium 内部日志，配合 `CefSettings.log_file` 输出到文件。排查 CEF 内部问题时不可或缺                                                          |
| `--disable-gpu`                |  ⭐⭐⭐⭐  | 禁用 GPU 加速。在远程桌面、虚拟机、低配机器上可避免白屏/黑屏/闪烁                                                                                    |
| `--disable-web-security`       |   ⭐⭐⭐   | 开发阶段禁用同源策略，方便本地资源跨域请求。**⚠️ 生产环境必须关闭！**                                                                                |
| `--ignore-certificate-errors`  |   ⭐⭐⭐   | 开发阶段忽略 SSL 证书错误，方便调试 HTTPS 接口。**⚠️ 生产环境必须关闭！**                                                                            |

### 🚀 生产环境

| 参数                                |   推荐度   | 说明                                                   |
|-------------------------------------|:----------:|--------------------------------------------------------|
| `--disable-features=TranslateUI`    | ⭐⭐⭐⭐⭐ | 禁用 Chromium 内置的翻译提示弹窗，桌面应用不需要此功能 |
| `--disable-features=SitePerProcess` |  ⭐⭐⭐⭐  | 禁用站点隔离，减少内存占用。对单窗口桌面应用效果明显   |
| `--disable-extensions`              |  ⭐⭐⭐⭐  | 禁用扩展加载，减少不必要的资源消耗                     |
| `--no-first-run`                    |  ⭐⭐⭐⭐  | 跳过首次运行向导                                       |
| `--disable-sync`                    |  ⭐⭐⭐⭐  | 禁用数据同步，桌面应用不需要 Chrome 账号同步功能       |
| `--metrics-recording-only`          |   ⭐⭐⭐   | 禁用指标数据上报，避免不必要的网络请求                 |
| `--no-pings`                        |   ⭐⭐⭐   | 禁用超链接 ping 追踪，保护隐私                         |

### 🖥️ 高 DPI / Windows 适配

| 参数                            |   推荐度   | 说明                                                                                                                                            |
|---------------------------------|:----------:|-------------------------------------------------------------------------------------------------------------------------------------------------|
| `--force-device-scale-factor=1` | ⭐⭐⭐⭐⭐ | 强制 100% 缩放。Windows 高 DPI 屏幕（150%/200%）下 CEF 可能出现内容模糊或尺寸异常，此参数可确保渲染清晰。如需支持系统缩放，可设为实际值如 `1.5` |

### 🎨 渲染稳定性

| 参数                                    |  推荐度  | 说明                                                                                                        |
|-----------------------------------------|:--------:|-------------------------------------------------------------------------------------------------------------|
| `--disable-gpu-compositing`             |  ⭐⭐⭐  | 禁用 GPU 合成，强制软件渲染。GPU 渲染不稳定时使用，性能会有所下降                                           |
| `--use-angle=d3d11`                     |  ⭐⭐⭐  | 指定 ANGLE 使用 Direct3D 11 后端。Windows 上默认推荐，避免 OpenGL 兼容性问题                                |
| `--disable-background-timer-throttling` | ⭐⭐⭐⭐ | 禁用后台定时器节流。后台页面需要执行定时任务（WebSocket 心跳、数据轮询）时必须开启                          |
| `--disable-renderer-backgrounding`      | ⭐⭐⭐⭐ | 禁用渲染进程后台化，确保页面切到后台后不被降速。与 `--disable-background-timer-throttling` 配合使用效果最佳 |

### 🌐 网络代理（按需配置）

| 参数                                      | 推荐度 | 说明                                                |
|-------------------------------------------|:------:|-----------------------------------------------------|
| `--proxy-server=127.0.0.1:8080`           | ⭐⭐⭐ | 开发阶段配合抓包工具（Fiddler/Charles）拦截网络请求 |
| `--proxy-bypass-list=localhost;127.0.0.1` |  ⭐⭐  | 代理绕过本地地址，避免本地资源请求被代理拦截        |

--remote-debugging-port=9222
--enable-logging --v=1

--disable-features=TranslateUI,SitePerProcess

```cpp
settings.locale = "zh-CN";
settings.remote_debugging_port = 0;           // 关闭远程调试
settings.log_severity = LOGSEVERITY_WARNING;  // 降低日志级别
settings.no_sandbox = false;                  // 启用沙箱
settings.persist_session_cookies = true;      // 保持登录状态
```

**命令行参数：**

```
--disable-features=TranslateUI
--disable-extensions
--no-first-run
--disable-sync
--metrics-recording-only
--no-pings
--force-device-scale-factor=1
--disable-background-timer-throttling
--disable-renderer-backgrounding
```

## 一、日志与调试

| 参数                                | 说明                                                                                                                                                           |
|-------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `--enable-logging[=stderr\|file]`   | 启用 Chromium 内部日志输出。默认输出到 stderr，指定 `file` 则输出到日志文件。配合 `CefSettings.log_file` 可指定日志文件路径                                    |
| `--v=<级别>`                        | 设置日志详细级别（0-99），0 为最少输出，数值越大日志越详细。示例：`--v=1` 启用基本日志，`--v=3` 启用详细日志                                                   |
| `--vmodule=<模块=级别,...>`         | 按源文件模块设置日志级别，比 `--v` 更精细。示例：`--vmodule=net/*=2,url_request=3`                                                                             |
| `--log-level=<级别>`                | 设置日志严重级别（0=INFO, 1=WARNING, 2=LOG_ERROR, 3=LOG_FATAL）                                                                                                |
| `--remote-debugging-port=<端口>`    | 启用 Chrome DevTools 远程调试，指定调试端口号。调试地址：`http://localhost:<端口>`，也可通过 `chrome://inspect` 连接。等效 `CefSettings.remote_debugging_port` |
| `--remote-debugging-address=<地址>` | 设置远程调试的监听地址，默认为 `127.0.0.1`。设为 `0.0.0.0` 可允许外部访问（仅限调试环境）                                                                      |
| `--remote-allow-origins=<来源>`     | 指定允许连接远程调试端口的来源列表，逗号分隔                                                                                                                   |
| `--js-flags=<标志>`                 | 向 V8 JavaScript 引擎传递标志。示例：`--js-flags="--expose-gc"` 暴露 `window.gc()` 垃圾回收函数                                                                |
| `--disable-javascript`              | 禁用 JavaScript（仅用于特殊场景）                                                                                                                              |

## 二、进程与沙箱

| 参数                            | 说明                                                                              |
|---------------------------------|-----------------------------------------------------------------------------------|
| `--no-sandbox`                  | 禁用沙箱安全机制。仅用于开发调试，生产环境不应使用。等效 `CefSettings.no_sandbox` |
| `--single-process`              | 以单进程模式运行（浏览器进程和渲染进程合并）。仅用于调试，存在安全风险            |
| `--process-per-tab`             | 每个标签页使用独立进程（增加内存占用，便于调试隔离）                              |
| `--in-process-gpu`              | GPU 进程作为浏览器进程内的线程运行，便于调试 GPU 相关问题                         |
| `--disable-gpu`                 | 禁用 GPU 硬件加速。用于排查 GPU 相关的渲染问题                                    |
| `--disable-gpu-compositing`     | 禁用 GPU 合成，强制使用软件渲染                                                   |
| `--disable-gpu-vsync`           | 禁用 GPU 垂直同步，可解除帧率限制                                                 |
| `--disable-software-rasterizer` | 禁用软件光栅化器                                                                  |
| `--enable-gpu-debugging`        | 启用 GPU 调试，每个 GL 命令后会调用 `glGetError()`                                |

## 三、网络与代理

| 参数                                | 说明                                                                                     |
|-------------------------------------|------------------------------------------------------------------------------------------|
| `--proxy-server=<地址:端口>`        | 设置 HTTP/HTTPS 代理服务器。示例：`--proxy-server=127.0.0.1:8080`                        |
| `--proxy-bypass-list=<主机列表>`    | 设置代理绕过列表，分号分隔。示例：`--proxy-bypass-list=localhost;127.0.0.1`              |
| `--proxy-pac-url=<URL>`             | 设置 PAC（代理自动配置）文件的 URL                                                       |
| `--host-resolver-rules=<规则>`      | 自定义 DNS 解析规则，用于测试。示例：`--host-resolver-rules="MAP example.com 127.0.0.1"` |
| `--ignore-certificate-errors`       | 忽略 SSL/TLS 证书错误，允许自签名证书。仅限开发调试使用                                  |
| `--ignore-urlfetcher-cert-requests` | 忽略 URLFetcher 的证书请求                                                               |
| `--disable-web-security`            | 禁用同源策略（CORS）限制。仅限开发调试使用，**生产环境严禁使用**                         |
| `--allow-running-insecure-content`  | 允许在 HTTPS 页面中加载 HTTP 内容                                                        |

## 四、缓存与存储

| 参数                        | 说明                                                  |
|-----------------------------|-------------------------------------------------------|
| `--disk-cache-dir=<路径>`   | 设置磁盘缓存目录路径。等效 `CefSettings.cache_path`   |
| `--disk-cache-size=<字节>`  | 设置磁盘缓存最大大小（字节）。设为 0 使用默认值       |
| `--media-cache-size=<字节>` | 设置媒体缓存最大大小（字节）                          |
| `--user-data-dir=<路径>`    | 设置用户数据目录（包含 Cookie、LocalStorage、缓存等） |
| `--no-proxy-server`         | 不使用任何代理服务器                                  |

| `--disable-accelerated-2d-canvas`     | 禁用 2D Canvas 硬件加速                                                                        |
| `--disable-accelerated-video-decode`  | 禁用硬件加速视频解码                                                                           |
| `--enable-webgl`                      | 强制启用 WebGL                                                                                 |
| `--disable-webgl`                     | 禁用 WebGL                                                                                     |
| `--use-angle=<后端>`                  | 指定 ANGLE 渲染后端（`gl`, `d3d9`, `d3d11`, `warp`, `swiftshader`）。示例：`--use-angle=d3d11` |
| `--use-gl=<实现>`                     | 指定 GL 实现（`desktop`, `angle`, `swiftshader`）                                              |
| `--force-gpu-mem-available-mb=<MB>`   | 强制设置 GPU 可用显存大小（MB），用于调试                                                      |
| `--disable-font-subpixel-positioning` | 禁用字体子像素定位渲染                                                                         |

| `--log-file=<路径>`                | 设置日志文件路径。等效 `CefSettings.log_file`                                                                                  |
| `--log-severity=<级别>`            | 设置日志严重级别（`default`, `info`, `warning`, `error`, `fatal`, `disable`）。等效 `CefSettings.log_severity`                 |

| `--locales-dir-path=<路径>`        | 设置本地化资源目录路径。等效 `CefSettings.locales_dir_path`                                                                    |

| `--framework-dir-path=<路径>`      | 设置框架目录路径（macOS 专用）。等效 `CefSettings.framework_dir_path`                                                          |

| `--background-color=<颜色值>`      | 设置默认背景颜色（ARGB 格式）。等效 `CefSettings.background_color`                                                             |

## 使用示例

在 `BrowserApp::OnBeforeCommandLineProcessing()` 中添加：

```cpp
void BrowserApp::OnBeforeCommandLineProcessing(
    const CefString &process_type,
    CefRefPtr<CefCommandLine> command_line) {
  if (process_type.empty()) {
    // 仅在主进程中设置
    command_line->AppendSwitchWithValue("remote-debugging-port", "9222");
    command_line->AppendSwitch("enable-logging");
    command_line->AppendSwitchWithValue("v", "1");
    command_line->AppendSwitch("disable-gpu");
    command_line->AppendSwitchWithValue("disable-features", "TranslateUI");
  }
}
```
