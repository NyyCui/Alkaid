# 瑶光台桌面

独立前端，仅负责界面与交互，通过 SDK 使用宿主能力。

- `index.html`、`1.css`、`runtime.css`、`experience.css`、`src/`：真实接入版。
- `prototype/`：用户原始原型备份，不进入运行资源。
- SDK 由相邻 alkaid 项目的 `scripts/build-desktop.py` 编译并一起输出。

当前接入运行时信息、能力查询、应用注册信息、普通应用启动/聚焦/关闭及退出平台。“能力查看器”由相邻 alkaid 项目的 `samples/inspector/` 提供，属于真实独立窗口、普通权限的随附应用。

桌面图标支持双击或键盘 Enter 打开；应用管理提供打开、切换与关闭，Dock 仅显示实际启动中的应用。状态暂以一秒轮询同步，同一时刻最多一个列表请求；数据不变时保留 DOM，刷新不清空已有内容。应用状态由宿主确定，前端不根据按钮点击推断已经运行或关闭。

安装流程已接入原生选包、宿主验签预览、未知发布者确认、后台任务查询、更新、恢复上一版本与卸载。`src/packages.js` 只处理 UI，不读取源包或执行签名/文件操作。安装应用可在宿主重启后恢复，卸载默认保留数据。

安装确认已展示存储与文件能力以及新增授权；文件和私有 KV 由宿主供给，可安装的便签示例已接入。网络代理按当前应用权限与端点授权调用。“应用管理”和“关于”仍是本页面内部面板。平台退出会关闭所有应用窗口。

普通浏览器预览请使用构建后的 web 目录，界面会显示“浏览器预览”。源码目录没有生成后的 SDK，不能直接双击 index.html 作为运行方式。


2026-11-04 桌面体验首轮：主桌面使用无原生标题栏窗口，品牌菜单、应用、工具、设置和任务入口保持固定；工具集中打包、插件和诊断。`src/interactions.js` 管理公共确认框、任务展示、搜索和桌面菜单，`experience.css` 沿用原视觉并统一控件与动效。

打包流程为填写信息 → 选择构建目录 → 主动选择输出位置 → 确认生成。关闭工作台可从任务入口恢复当前会话任务，返回编辑保留表单。新图标及多尺寸 ICO 位于 `assets/`，构建脚本同步到宿主并嵌入启动程序。Windows 通知区支持双击显示桌面及右键退出。
